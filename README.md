## About Me

I build React interfaces that hold up under real usage — not just the happy path. My focus is the layer users actually touch: component architecture that stays clean as features grow, state that doesn't fight you, and UI that handles loading, error, and edge-case states as carefully as the ideal one.

Over the last several months I've worked inside two live products at **Coretecture**, shipping UI through 15+ rounds of real product feedback — the kind of environment where "it works on my machine" isn't good enough. I've learned to move fast without leaving a mess behind for the next person who touches the code.

I'm currently looking for a **Frontend Developer** role where I can keep doing exactly this — turning ambiguous product requirements into interfaces people don't have to think about.

- Took the interface from wireframe to a working, testable extension end-to-end — UX design, implementation, and cross-browser debugging across live news and editorial sites.
